# Общий архив — универсальные промпты A1–A5

Версия комплекта: **2.0.0**. Это **первичные инструкции для повторного применения**, а не самостоятельный проект, оркестратор или обязательный GitHub-процесс.

**A1–A4 — четыре основных разработчика; A5 — главный технический координатор, архитектор и интегратор.** Технологические специализации A1–A4 в универсальной версии отсутствуют: назначение определяет каждый проект.

## Как подключить

Первичные универсальные инструкции **дополняются** двумя слоями конкретного проекта:

1. **Общие правила**: \`COMMON.md\`.
2. **Универсальная роль**: для A1–A4 — \`DEVELOPER.md\` и файл соответствующего ID; для A5 — \`A5.md\`.
3. **Общий промпт проекта**: цель, технологии, архитектура, полномочия, принятый workflow и критерии.
4. **Проектный промпт конкретного агента/задачи**: специализация, файлы, контракты, зависимости и поставка.

Порядок перечисления — способ **уточнять контекст**, а не разрешение отменять системные ограничения или прямые решения пользователя. Проектные документы должны быть совместимы друг с другом. Если есть противоречие, агент выявляет его и согласует решение, а не молча выбирает удобный текст.

Допускаются \`PROJECT.md\`, \`AGENTS.md\`, OpenSpec, Issue или иные принятые материалы. **Не нужно создавать дополнительные документы, GitHub Issues/PR, CI, lease или новый gate только потому, что в архиве есть шаблоны.** Применяй процесс, выбранный конкретным проектом.

### Пример

Для ChemSim конкретное назначение A2 может быть «парсер уравнений», A4 — «численный решатель», а в другом проекте A2 может быть разработчиком backend. Базовый промпт остаётся одним и тем же. Универсальная роль A5 не меняет существующих полномочий агента проекта без отдельного решения его владельца.

## Правила поддержки архива

- Существующие проекты **не переключаются автоматически** на новую версию. Для долгоживущих работ закрепляй commit SHA используемых промптов и переходи на новую версию после проверки проектных назначений.
- \`proposals/\` — предложения и исследования, **не действующие инструкции**. Часть старых рекомендаций намеренно оставлена на уровне проекта/инфраструктуры, а не включена в общий промпт.
- Изменяй семантику первичных ролей осмысленно: сравни с действующими проектами и документируй переход.

## Происхождение

Первое поколение универсального архива создавалось на основе пользовательского протокола и опыта [ChemSim](https://github.com/AndreyCokol/ChemSim) и [My_shelter](https://github.com/AndreyCokol/My_shelter/blob/87c1303373aae796f714938342d699fd09c0a2a2/docs/book-01/agents/prompts/COMMON.md). Версия 2.0 отделяет постоянные правила работы от предметных назначений. Исходные промпты проектов остаются самостоятельными и не переписываются этим архивом.
