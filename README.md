# Общий архив

Универсальные рабочие промпты для команды разработки A1–A5. Репозиторий не привязан к продукту, движку или языку программирования.

| Файл | Назначение |
|---|---|
| [COMMON](prompts/COMMON.md) | Общий протокол аудита, работы, Git, контрактов и проверки |
| [A1](prompts/A1.md) | Основной разработчик: ядро и доменная логика |
| [A2](prompts/A2.md) | Основной разработчик: сценарии и API |
| [A3](prompts/A3.md) | Основной разработчик: данные и интеграции |
| [A4](prompts/A4.md) | Основной разработчик: интерфейсы и пользовательские потоки |
| [A5](prompts/A5.md) | Главный координатор, архитектор, ревьюер и интегратор |
| [PROJECT.template](PROJECT.template.md) | Назначения и параметры конкретного проекта |

## Применение
1. Заполни PROJECT.template.md в целевом проекте как PROJECT.md, укажи точные области владения и критерии.
2. Каждому агенту передай COMMON.md, его индивидуальный промпт и PROJECT.md.
3. A5 согласует назначения и зависимости; A1–A4 реализуют свои модули.
4. Соблюдай существующие решения владельца и ограничения среды. Этот архив не изменяет роли уже работающих проектов автоматически.
5. Версию используемых шаблонов закрепляй SHA/тегом; обновления переноси после проверки совместимости.

Специализации A1–A4 — начальная схема; в конкретном проекте они адаптируются с явными непересекающимися назначениями. A5 остаётся главным координатором.

## Происхождение
Общий протокол перенесён в универсальную редакцию из пользовательского протокола A1–A5 и [общего промпта My_shelter](https://github.com/AndreyCokol/My_shelter/blob/87c1303373aae796f714938342d699fd09c0a2a2/docs/book-01/agents/prompts/COMMON.md).
Удалены зависимости от книги, игры, движка, платформы и конкретных путей. Руководство и интеграция переданы A5. Проектные документы исходного репозитория сохраняют собственный смысл и не заменяются этими шаблонами.
