# Общий архив
Первичные универсальные промпты команды A1–A5 · версия 2.0.

## Состав
- [COMMON](prompts/COMMON.md) — общие принципы работы.
- [A1](prompts/A1.md), [A2](prompts/A2.md), [A3](prompts/A3.md), [A4](prompts/A4.md) — основные разработчики без постоянной специализации.
- [A5](prompts/A5.md) — главный технический координатор и интегратор.
- [Шаблон проекта](PROJECT.template.md) — контекст и применимые процедуры.
- [Шаблон задания](TASK.template.md) — конкретный результат и приёмка.
- [Предложения и история аудитов](proposals/) — аналитические материалы, не действующие инструкции.

## Применение
Передайте агенту COMMON + его первичную роль + контекст проекта + его проектное назначение/задачу.
Проект определяет специализации A1–A4, стек, компоненты, владельцев, проверки и процесс работы. A5 координирует в пределах делегирования владельца. Утверждение, GitHub, PR, CI, lease и MVP применяются, когда установлены проектом.
Файлы шаблонов необязательны: эквивалентные инструкции могут находиться в другом документе или задании пользователя.

Версия 2.0 устраняет постоянные специализации и повторение общего процесса в ролях, отделяет проектные процедуры от первичных принципов. Старые аудиты относятся к указанному в них baseline; перенос в действующий проект требует проверки совместимости.
