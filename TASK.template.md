# TASK.template — необязательное задание конкретному агенту

Этот формат используют **только при необходимости**. Эквивалентом может быть Issue, задача в рабочем плане или ясное сообщение владельца.

- **Агент / ID:** <A1–A5>
- **Что требуется:** <результат>
- **Зачем:** <обоснование>
- **Границы и зависимости:** <какие компоненты затронуты / с кем согласовать>
- **Критерий готовности:** <наблюдаемый результат>
- **Допустимые действия / ограничения:** <при необходимости>
- **Проверка:** <подходящий способ; N/A с причиной, если неприменимо>
- **Состояние / блокер:** <при необходимости>
- **Ссылка на результат:** <файл, commit, PR, документ, сообщение — если существует>

Не считай сам факт создания шаблона или заполнения полей разрешением на внешние действия, изменение чужой области или выпуск проекта.
